Design principle: Action-oriented grouping
Instead of grouping by category (Timesharing, Decision-Making, etc.), the dashboard groups by what you need to do next. This answers the parent's #1 question: "What should I work on?" Categories are still shown as labels, but the primary sort is by action needed. Parents can toggle back to the category view if they prefer.
