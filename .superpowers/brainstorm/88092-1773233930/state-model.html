Sync shortcut
When parents work together in a live session, they skip draft → in-review → contested and go straight from learning to agreed (the existing "completed" state, renamed).
Contest loop
contested ↔ in-review can cycle back and forth as parents edit. Each edit swaps whose turn it is. Either parent can accept at any time to move to agreed.

Key transitions

Draft submitted → in-review
Reviewer accepts → agreed
Reviewer edits → contested
Drafter accepts edits → agreed
Drafter re-edits → in-review
Both sign → signed
