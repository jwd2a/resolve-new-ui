Key UX decisions
  • Same form, different chrome — the form fields are identical to sync mode. Only the banner and action buttons change.
  • Diffs are inline — changed fields show the edit highlighted with the original below. Unchanged fields are dimmed.
  • Save & Continue Later — drafts auto-save so parents can step away mid-section.
  • Escape hatch to sync — the draft banner always offers "start a live session" as an alternative.
